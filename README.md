# AI / ML Practice

A personal practice repo for exploring AI and ML topics through hands-on experiments and notes.

## Docs

Open in browser: **[AI / ML Practice Docs](https://donthuavinashbabu.github.io/ai-ml/)**

Layout: left-side menu, right-side page content.

First-time setup (once): **Settings → Pages → Build and deployment → Source: GitHub Actions**.
After that, each push to `main` publishes `docs/` automatically.

## Focus areas

- LLMs (Claude, GPT, and others)
- Agents
- RAG (Retrieval-Augmented Generation)
- Vector databases
- Related tooling and patterns

## Purpose

Learn by building small, focused examples — not a production project.
