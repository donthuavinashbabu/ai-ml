# AI / ML Practice

A personal practice repo for exploring AI and ML topics through hands-on experiments and notes.

## Docs

Browse the notes in [`/docs`](./docs/index.md).

- Agents
- RAG (Retrieval-Augmented Generation)
- Vector databases
- Related tooling and patterns

Learn by building small, focused examples — not a production project.
